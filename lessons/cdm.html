What this is for

What is an item? explained item difficulty with a matrix of item features and kept every respondent on one continuum. This lesson keeps the matrix and drops the continuum. Suppose respondents differ not in how much of something they have but in which skills they have: a student who can find a common denominator but can’t borrow from a whole number needs different teaching from one with the opposite gap, even if both get half the items right. Latent class analysis puts respondents in a few unobserved groups; cognitive diagnosis builds the groups from profiles of skills, with a matrix saying which skills each item needs. Constructs and construct maps asked whether a construct is a continuum or a set of classes, and summary statistics couldn’t tell. Here we fit both and see which the data prefer.

Goals

By the end of this lesson you should be able to:

  • write down the latent class model, fit it with poLCA, and choose the number of classes;
  • say why ordered latent classes behave like a continuum cut into pieces, and what would be evidence of something else;
  • read a Q-matrix and say which items a skill profile should answer correctly under DINA;
  • fit DINA and G-DINA with GDINA, and read guessing, slipping and the share of respondents with each skill;
  • compare a cognitive diagnosis model with the Rasch model and the 2PL, and use empirical Q-matrix validation with care.

Core ideas

Latent classes

Recall from Constructs and construct maps: latent classes are unobserved groups inside each of which people are alike. Ordered classes close together gave nearly the same sum scores and item-rest correlations as a continuum, and telling them apart was left to models fit to the responses.

A latent class model says each respondent belongs to one of \(C\) classes, class \(c\) holding a share \(\pi_c\) of the population, and that within a class each item has its own probability of success, \(p_{ic}\). Given the class, responses are independent: local independence, with a class in place of \(\theta\). The probability of respondent \(j\)’s responses is a mixture over the classes, \[\Pr(\mathbf{x}_j) = \sum_{c=1}^{C} \pi_c \prod_{i} p_{ic}^{\,x_{ij}}\,(1 - p_{ic})^{1 - x_{ij}}.\] The model comes from Lazarsfeld’s latent structure analysis (Lazarsfeld & Henry, 1968); Goodman (1974) took up its estimation and when its parameters are identified. With \(I\) items it has \(C - 1\) class shares and \(C \times I\) item probabilities. It is fit by EM: from a guess at the item probabilities, compute each respondent’s posterior probability of each class, re-estimate the item probabilities with responses weighted by those posteriors, and repeat. We use the poLCA package (Linzer & Lewis, 2011).

Read the formula from the inside out. Inside class \(c\), each item contributes \(p_{ic}\) if it was answered correctly and \(1 - p_{ic}\) if not, and local independence lets us multiply those factors into the probability of the whole pattern if the respondent were in class \(c\). We don’t know the class, so each class’s product is weighted by its share \(\pi_c\) and the weighted products are added. Each term’s part of the sum is the posterior probability that the respondent is in that class, which is how EM assigns respondents.

A latent class model makes no assumption of a continuum, which is what a theory of types, such as Moffitt’s account of antisocial behaviour, calls for; it can also describe how responses hang together without one.

Classes or a continuum?

A latent class model has no \(\theta\). All it has is a set of classes, each a share of respondents and a row of success rates, one per item, like the rows of the table in the last widget. So the question “types or a continuum?” has to be asked of those rows. What pattern in them would a continuum leave behind?

Draw each class’s row as a line across the items, easiest to hardest: a profile. If the classes are really types, respondents who differ in which items they find hard, the profiles cross: one class beats another on some items and loses on others. If the classes are levels of one thing, each class does better than the class below it on every item, and the profiles stack without crossing.

However many levels you choose, the profiles stack: 0 of 10 items are out of order. Add the type and its profile zigzags across the rest, putting all ten out of order. So a latent class model that finds stacked profiles has found what a continuum would give it, a continuum cut into a few levels, not evidence of types. The converse holds too: a Rasch model whose \(\theta\) takes only a few values, ordered classes by another name, gives nearly the same item estimates as the Rasch model’s conditional likelihood once it has at least \((I + 1)/2\) of them (Lindsay, Clogg & Grego, 1991). Evidence for classes as something other than a continuum has to come from crossings, classes that differ in which items they find hard.

Cognitive diagnosis: classes built from attributes

Recall from What is an item?: the LLTM wrote each item’s easiness as \(\beta_i = \sum_k q_{ik}\eta_k\), where \(q_{ik}\) is 1 if item \(i\) has feature \(k\). The matrix of \(q_{ik}\) described the items, and respondents stayed on one continuum.

Cognitive diagnosis uses such a matrix differently. Each respondent has a profile \(\boldsymbol\alpha_j = (\alpha_{j1}, \dots, \alpha_{jK})\) of binary attributes, skills they have (\(\alpha_{jk} = 1\)) or lack. \(K\) attributes give \(2^K\) profiles, and each profile is a latent class. The Q-matrix says which attributes each item requires: \(q_{ik} = 1\) if item \(i\) needs attribute \(k\). In the LLTM the matrix explained how hard an item is; here it decides which classes an item can tell apart. A cognitive diagnosis model (CDM) is therefore a restricted latent class model (Haertel, 1989): the classes are fixed in advance by the attributes, and the Q-matrix ties their item probabilities together (Rupp, Templin & Henson, 2010).

The classic example is fraction subtraction, from Kikumi Tatsuoka’s work on diagnosing students’ errors (Tatsuoka, 1983; the data as analysed by Tatsuoka, 2002). Twenty items are coded on eight attributes, giving \(2^8 = 256\) profiles. The attribute labels are those of the CDM package documentation, which takes the Q-matrix from DeCarlo (2011) and de la Torre and Douglas (2004).

A profile also describes a respondent, so it can be handed to a simulator. Zhou, Liu, Tang and Wilson (2026), a preprint, took 15 of these fraction items coded on five attributes, wrote each attribute profile as a short description of a student, and asked language models to answer as that student. Answering with no profile, the models were more accurate and more alike than the 536 students. Given profiles, their scores spread more like the students’, and the 1PL difficulties from their answers came closer to the students’ difficulties: in the strongest case, the rank correlation rose from 0.24 to about 0.9. AI and psychometrics takes up language models as simulated respondents more generally.

DINA: all or nothing

The DINA model (“deterministic inputs, noisy and gate”; Junker & Sijtsma, 2001) asks one question per item: does the respondent have every attribute it needs? Write \[\eta_{ij} = \prod_{k} \alpha_{jk}^{\,q_{ik}},\] which is 1 if they do and 0 if they lack any. Then \[\Pr(x_{ij} = 1 \mid \boldsymbol\alpha_j) = (1 - s_i)^{\eta_{ij}}\, g_i^{\,1 - \eta_{ij}}.\] The slip \(s_i\) is the chance that a respondent with everything the item needs still gets it wrong; the guess \(g_i\) is the chance that one without gets it right. Each item has two parameters, because the model splits the \(2^K\) classes into two groups per item. Having some of the required attributes counts for nothing.

If you’ve done From the 1PL to the 4PL: its section on ceilings and slips pointed here. DINA’s \(1 - s\) and \(g\) are an upper and a lower asymptote, like the 4PL’s \(u\) and \(c\), with nothing in between.

Other models relax the rule. In DINO, any one required attribute is enough (Templin & Henson, 2006), which suits a symptom that several conditions can produce. G-DINA (de la Torre, 2011) gives each combination of an item’s \(K_i\) required attributes its own probability, \(2^{K_i}\) of them, and contains DINA and DINO; the log-linear CDM (Henson, Templin & Willse, 2009) is an equivalent family written as a logistic regression on the attributes and their interactions. DINA assumes an item is solved by a chain of steps that must all succeed, as fraction subtraction may be, and spends two parameters per item; G-DINA lets the data say how partial mastery counts, at the price of \(2^{K_i}\) parameters per item, which a small sample may not support. How well each predicts held-out responses says which trade pays in a given dataset (problem 3).

Tying the attributes to a continuum: the higher-order model

DINA says how an item depends on a profile, but not how profiles are spread among respondents. Left free, that spread is a share \(\pi\) for every one of the \(2^K\) profiles, with nothing linking them. Do respondents who have one attribute tend to have the others? The higher-order model (de la Torre & Douglas, 2004) answers yes, through one continuous trait. Each respondent has a \(\theta_j\), normally distributed, and given \(\theta_j\) the attributes are independent, with \[\Pr(\alpha_{jk} = 1 \mid \theta_j) = \frac{\exp(\lambda(\theta_j - \delta_k))}{1 + \exp(\lambda(\theta_j - \delta_k))}.\] Each attribute has a threshold \(\delta_k\), the point on \(\theta\) where it is as likely mastered as not, and \(\lambda\) says how sharply mastery rises around it. This is a Rasch-type model with the attributes in place of the items, except that the attributes are never observed. The share of a profile is the product of these probabilities, averaged over \(\theta\), so the \(2^K - 1\) free shares become \(K\) thresholds (and \(\lambda\)). With \(\lambda\) fixed at 1, as GDINA does by default, that is one parameter per attribute.

What does an item look like against \(\theta\) now? Below the attributes’ thresholds a respondent probably lacks something the item needs and sits near the guess; above them they probably have it all and sit near \(1 - s\).

How many classes, which Q-matrix, and why not IRT?

Eight attributes give 256 profiles, so an unrestricted distribution over them has 255 parameters, to be estimated from 536 students in the fraction data. Two restrictions shrink that. The higher-order model above needs 8, one per attribute. An attribute hierarchy allows only profiles consistent with an order of learning, ruling out an advanced skill without its prerequisite (Templin & Bradshaw, 2014). Both move a CDM toward a continuum.

The Q-matrix usually comes from content experts, and may be wrong. Empirical Q-matrix validation looks for better entries. The PVAF method (de la Torre & Chiu, 2016) asks, item by item, for the smallest set of attributes whose G-DINA success probabilities carry at least a set share (by default 95%) of the variation that the item’s full set of attributes would give. It can point to items whose coding deserves a second look; a suggestion is a hypothesis about the item, to be checked against what the item asks and by refitting. Is a CDM better than IRT? The models aren’t nested, so we compare them by AIC and BIC, or by predicting held-out responses (problem 3). Ma, Liu, Kanopka, Ma and Domingue (2026) did the latter, with the IMV, on 11 datasets previously analysed with CDMs, including the ECPE and the fraction data used below. When each respondent was assigned their most probable profile, the 2PL predicted held-out responses better than DINA and G-DINA in every dataset. When predictions used each respondent’s probability of mastering each attribute, a CDM did better in 6 of the 11, by small margins (an IMV under 0.02). G-DINA in particular fit the data it was estimated on much better than it predicted new responses. Why might a CDM lose on data it was built for? The IMV site has an interactive version of the simulation side: data come from DINA with correlated skills, and as the correlation rises the profiles collapse toward one dimension and the 2PL closes the gap.

NoteGo deeper: with one attribute, the higher-order DINA item is a 4PL

Assumptions: the DINA model for item \(i\), with guess \(g\) and slip \(s\); a higher-order model in which, given a continuous \(\theta\), attribute \(k\) is mastered with probability \(\text{logistic}(\lambda(\theta - \delta_k))\), independently across attributes.

Given \(\theta\), a respondent answers correctly either by having every required attribute and not slipping, or by lacking one and guessing: \[\Pr(x_i = 1 \mid \theta) = (1 - s)\,P_{\text{all}}(\theta) + g\,\big(1 - P_{\text{all}}(\theta)\big) = g + (1 - s - g)\,P_{\text{all}}(\theta),\] where \(P_{\text{all}}(\theta) = \prod_{k:\,q_{ik}=1} \text{logistic}(\lambda(\theta - \delta_k))\) is the probability of having all of them.

With one required attribute, \(P_{\text{all}}(\theta) = \text{logistic}(\lambda(\theta - \delta))\), and \[\Pr(x_i = 1 \mid \theta) = g + \big((1 - s) - g\big)\,\frac{\exp(\lambda(\theta - \delta))}{1 + \exp(\lambda(\theta - \delta))},\] which is the 4PL with \(c = g\), \(u = 1 - s\), slope \(a = \lambda\) and difficulty \(b = \delta\). The curve’s location and slope belong to the attribute: every item that needs only attribute \(k\) has the same slope and difficulty and differs only in its asymptotes.

With \(m \ge 2\) attributes, \(P_{\text{all}}\) is a product of logistic curves, which isn’t a logistic curve. In log-odds its lower tail has slope \(m\lambda\) and its upper tail slope \(\lambda\), so it leaves the floor abruptly and approaches the top slowly; and at the largest threshold every other factor is above 0.5 and that one equals 0.5, so its midpoint sits to the right of every \(\delta_k\). As \(\lambda\) grows, each factor becomes a step at \(\delta_k\) and the product a step at the largest threshold. So the higher-order DINA is a unidimensional IRT model whose item curves are built from the Q-matrix. DeCarlo (2011) fits a logistic version of DINA with software for latent class analysis, along the same lines.

Simulate

The code simulates 1,000 respondents answering ten items on three attributes and fits DINA with GDINA (Ma & de la Torre, 2020), then G-DINA, then DINA with one wrong Q-matrix entry. The first run takes about half a minute, most of it installing GDINA.

With the seed as written, guesses and slips come back within about 0.05 of the truth, except item 7’s slip (0.18 true, 0.27 estimated), on the item needing all three attributes. Each attribute is classified correctly for 94% to 95% of respondents, the whole profile for 84%. AIC prefers DINA (10,692) to G-DINA (10,712), as it should: DINA generated the data. Telling the model that item 4 needs only A1 (it needs A1 and A2) sends its slip from 0.19 to 0.50: respondents with A1 but not A2 now count as able, and get it wrong. The AIC rises to 10,828. Try n <- 300, or make some profiles rare in share.

Download this code to run it as large as you like in your own R session.

With real data

cdm_ecpe has two jobs: the latent class example, fit without a Q-matrix to ask whether its classes come out ordered, and the contrast for cognitive diagnosis, a test whose attributes may be one scale in disguise. frac20 is the main example, Tatsuoka’s fraction subtraction items. Both tables carry their Q-matrix in Qmatrix__ columns. Download the code; it needs poLCA, GDINA and mirt (Chalmers, 2012).

class_probs <- function(fit) {
  P <- sapply(fit$probs, function(p) p[, 2])   # classes x items: P(correct)
  o <- order(rowMeans(P))
  list(P = P[o, , drop = FALSE], share = fit$P[o])

Both routes through the ECPE, classes without a Q-matrix and profiles with one, arrive at ordered groups. In the fraction data the Q-matrix adds information, but the model that uses it best ties the attributes to one continuum.

Whether a test’s attributes behave as separate skills or collapse toward one continuum, as in both datasets here, is hard to know in advance, and AIC and BIC can disagree about it. Responses the models haven’t seen are the acid test: fit a CDM and a unidimensional model, compare how well each predicts held-out responses (problem 3), and let that comparison guide the choice.

Problems

  1. The DINA likelihood. Write the likelihood of one respondent’s responses under DINA as a latent class model over the \(2^K\) profiles. Show that with a single attribute (\(K = 1\)), DINA is a two-class latent class model whose item probabilities are \(g_i\) in one class and \(1 - s_i\) in the other. How many parameters does each model have, and are they the same model?
  2. The Q-matrix in an LLTM. Fit resp ~ 0 + Qmatrix__1 + ... + Qmatrix__8 + (1 | id) to frac20 with glmer, as in What is an item? (PS7#2 B). Do items with the same Q row have similar Rasch difficulties? What does the LLTM assume about attributes that DINA doesn’t, and the reverse?
  3. Held out. Hold out a random 20% of frac20 responses (set them to missing), fit the Rasch model, the 2PL, DINA and the higher-order DINA to the rest, and compute each model’s IMV over the Rasch model on the held-out responses (Model fit and out-of-sample prediction). Does the ranking agree with AIC, and with what Ma et al. (2026) found for these data? The IRW vignette Calculating IMV values has the cross-validation code. Then run the full PVAF analysis: which suggested changes make sense for the items as written? (PS7#2 D.)
  4. Skill reports from a state test. A district wants attribute-level reports for each student from a state mathematics test built from a blueprint of content strands, not a Q-matrix. Advise them. What would you want to see before any report goes home?
  5. Design a Q-matrix. Write a Q-matrix for eight items on three attributes in which each attribute has an item that needs it alone. Why does that matter for telling the \(2^3\) profiles apart under DINA? Try a Q-matrix without such items in the simulation.
  6. Challenge (open). When attributes form a hierarchy, as the ECPE’s appear to, is a CDM a new kind of model or a unidimensional model with cut points?
